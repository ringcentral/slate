# Maps

A map is a GeoJSON file generated by Allphins (pre-computed exposure atlases, reference layers). Maps are shared across the platform and read-only.

## Map Object Attributes

| Attribute    | Type        | Description                          |
|--------------|-------------|--------------------------------------|
| `id`         | _int_       | Unique identifier for the map.       |
| `name`       | _string_    | Name of the map.                     |
| `file`       | _string_    | URL of the GeoJSON file.             |
| `created_at` | _timestamp_ | Creation date.                       |
| `updated_at` | _timestamp_ | Last update date.                    |

## Retrieve all maps

```shell
curl https://api.allphins.com/api/v1/maps/ \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

> The above command returns JSON structured like this:

```json
{
  "count": 1,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": 1,
      "name": "Atlantic hurricane cones 2024",
      "file": "https://storage.googleapis.com/.../maps/atlantic_2024.geojson",
      "created_at": "2024-05-20T07:52:55.491729Z",
      "updated_at": "2024-05-20T07:52:55.491729Z"
    }
  ]
}
```

### HTTP Request

`GET https://api.allphins.com/api/v1/maps/`

## Retrieve a map

```shell
curl https://api.allphins.com/api/v1/maps/1/ \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

### HTTP Request

`GET https://api.allphins.com/api/v1/maps/:id/`

### URL Parameters

| Parameter | Description                |
|-----------|----------------------------|
| `id`      | The ID of the map to fetch |

# Exposure Maps

An exposure map is a user-requested map rendering of exposure for a set of policies, risks, a scenario, or a portfolio. Creation kicks off asynchronous computation; the `ready` flag flips to `true` and `file` points to the rendered GeoJSON once complete.

## Exposure Map Object Attributes

| Attribute       | Type        | Description                                                                |
|-----------------|-------------|----------------------------------------------------------------------------|
| `id`            | _UUID_      | Unique identifier for the exposure map.                                    |
| `name`          | _string_    | Name of the exposure map.                                                  |
| `parameters`    | _dict_      | Parameters used to compute the map (see below).                            |
| `kepler_config` | _dict_      | Kepler.gl configuration used for rendering, if any.                        |
| `ready`         | _bool_      | `true` once the map has been computed.                                     |
| `file`          | _string_    | URL of the rendered GeoJSON file (`null` until `ready`).                   |
| `created_at`    | _timestamp_ | Creation date.                                                             |
| `updated_at`    | _timestamp_ | Last update date.                                                          |

## Create an exposure map

Triggers asynchronous computation of an exposure map. The response returns the map in `ready=false` state; poll the retrieve endpoint until `ready=true`.

### HTTP Request

`POST https://api.allphins.com/api/v1/exposure_maps/`

### Payload

| Parameter       | Type     | Required | Description                                                        |
|-----------------|----------|----------|--------------------------------------------------------------------|
| `name`          | _string_ | No       | Name of the map.                                                   |
| `parameters`    | _dict_   | Yes      | Must include `exposure_parameters` (see below).                    |
| `kepler_config` | _dict_   | No       | Kepler.gl configuration.                                           |

`parameters.exposure_parameters` must contain **one of**:

| Field            | Type           | Description                                                          |
|------------------|----------------|----------------------------------------------------------------------|
| `policies`       | _list[int]_    | Policy IDs — renders policy exposure.                                |
| `scenario_id`    | _UUID_         | Scenario UUID — renders scenario exposure.                           |
| `is_risk_map`    | _bool_         | Set to `true` to render a risk map.                                  |
| `portfolio_name` | _string_       | Portfolio name — renders scenario-list exposure.                     |

```shell
curl https://api.allphins.com/api/v1/exposure_maps/ \
  -X POST \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -d '{"name":"Client A risk map","parameters":{"exposure_parameters":{"is_risk_map":true}}}'
```

<aside class="notice">
If <code>exposure_parameters</code> contains <code>computation_date</code>, it is silently ignored.
</aside>
